### 本轮踩到的坑（重要）
1. **新增 `class_name` 后必须先 `--headless --import` 再跑**，否则全局类缓存没更新，出现 "Could not find type BulletWeapon" 级联解析错误。
2. **合成鼠标点击必须分帧**：同一帧内连续 push press+release，Button 不会发 `pressed`；分成两帧（中间隔 ~0.15s）才生效。真实用户点击天然分帧，所以不是 bug。
3. 函数名和成员变量同名（`_click_stage` 变量 + 函数）会报 "same name as a previously declared variable"。
4. `_probe` 里提前 return 的条件漏写新开关，会让整段探针静默不执行——排查时先加 print。
