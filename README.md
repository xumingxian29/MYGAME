# 暗夜幸存者

一个用 **Godot 4.7.2** 写的 Vampire Survivors 类自动战斗生存游戏。桌面和手机浏览器都能直接玩。

**在线试玩：<https://xumingxian29.github.io/MYGAME/>**

---

## 玩法

存活越久分数越高。角色自动攻击，你只需要走位；升级时三选一加强属性；蓝条满了放一次主动技能。

**安全区会不断收缩**（吃鸡式毒圈）：圈缩到视野里之后战场就只剩这么大，缩到 0 时谁也活不了，
所以一局最长 **6 分 30 秒**必然结算。圈外每秒掉 1%~18% 的最大生命，
屏幕边缘的紫色/红色三角指向圈心。

### 三个职业

| 职业 | 定位 | 血量 | 主动技能 |
|---|---|---|---|
| 战士 | 近战 · 高血 | 180 | **旋风斩**：1.2 秒无敌，劈开并击退周围敌人 |
| 法师 | 远程 · 高伤 | 100 | **奥术新星**：大范围爆伤，命中者减速 2.5 秒 |
| 射手 | 远程 · 高射速 | 110 | **箭雨**：向四周射出 14 支穿透箭矢 |

### 操作

| | 桌面 | 手机（横屏） |
|---|---|---|
| 移动 | `WASD` / 方向键 | 左下虚拟摇杆（推一半就是半速） |
| 技能 | `空格` | 右下技能键（蓝条满时变金色） |
| 升级选卡 | 点卡片 或 `1` `2` `3` | 点卡片 |
| 死亡后 | `R` 再来一局 · `P` 换人 | 点按钮 |

## 本地运行

需要 Godot 4.7.2。

```bash
# 编辑器里跑
godot --path .

# 直接跑
godot --path . MY主场景.tscn
```

没有触摸屏的电脑也想试摇杆，加 `-- --touch` 强制开触屏模式（此时用鼠标拖就是手指）。

## 导出 Web 并发布

```bash
./deploy_pages.sh            # 导出 + 推送到 gh-pages 分支
./deploy_pages.sh --no-export   # 只重推现有 build/web
```

脚本会把 `build/web` 里的产物打进一份**只有单个提交**的临时仓库强制推送，
所以 40MB 的 wasm 不会在分支历史里逐次堆叠。

本地预览（不要用 `file://` 直接打开，必须走 HTTP）：

```bash
python serve.py 8080          # http://127.0.0.1:8080/
python serve.py 8080 --lan    # 同一 Wi-Fi 的手机也能打开
```

web/shell.html       自定义加载页（进度条、失败提示、竖屏提示）

## 兼容性

- 渲染后端固定 **GL Compatibility**（Web 唯一可用的后端）
- 用 **nothreads** 模板导出，不依赖 `SharedArrayBuffer`，所以 GitHub Pages 这类无法下发
  `Cross-Origin-Opener-Policy` 的静态托管也能直接跑
- 字体内嵌 `Noto Sans SC` 子集（Web 上 `SystemFont` 会静默退化，必须内嵌）
- 存档存在浏览器 IndexedDB 的 `/userfs` 下，换设备不同步
