# 暗夜幸存者

一个用 **Godot 4.7.2** 写的 Vampire Survivors 类自动战斗生存游戏。桌面和手机浏览器都能直接玩。

**在线试玩：<https://xumingxian29.github.io/MYGAME/>**

---

## 玩法

存活越久分数越高。角色自动攻击，你只需要走位；升级时三选一加强属性；蓝条满了放一次主动技能。

**地图是一间间迷宫房**：每张图程序化生成 9 个房间 + 走廊，墙是实心的，绕不进去。
其中一间是**商人密室**——走进去就能用金币买药。打完整张图的 Boss 会在原地开**四扇传送门**
（单卡 / 双卡 / 破甲弹 +3 / 金币 +90），**踩上去不会直接走**，面板里点「继续前进」才传。
**每深入一张图，敌人全部属性 +10%（累乘）**，没有时间上限——死了才结算。

**升级只给卡，不回血；传送也不回血**。血只有四个来源：脱战自然回复、Boss 战后 15%、
通关补满、商人。所以「这一波要不要绕回商人那儿」是一个真的要权衡的决定。

**视野里同时最多 20 只怪**（Boss 战 10 只）。超出的会被推回屏幕外等着，
而不是原地蒸发——屏外仍然排队，但画面里的压力是恒定的。

### 三个职业

| 职业 | 定位 | 血量 | 主动技能 |
|---|---|---|---|
| 战士 | 近战 · 高血 | 180 | **旋风斩**：1.2 秒无敌，劈开并击退周围敌人 |
| 法师 | 远程 · 高伤 | 100 | **奥术新星**：大范围爆伤，命中者减速 2.5 秒 |
| 射手 | 远程 · 高射速 | 110 | **箭雨**：向四周射出 14 支穿透箭矢 |

### 操作

| | 桌面 | 手机（横屏） |
|---|---|---|
| 移动 | `WASD` / 方向键 | 左下虚拟摇杆（推一半就是半速） |
| 技能 | `空格` | 右下技能键（蓝条满时变金色） |
| 暂停 / 继续 | `P` / `ESC` | 右上「暂停」键（暂停后变成「继续」） |
| 返回主菜单 | 先按 `P`/`ESC`，再点面板里的「返回主菜单」 | 先点「暂停」，再点面板里的「返回主菜单」 |
| 升级选卡 | 点卡片 或 `1` `2` `3` | 点卡片 |
| 死亡后 | `R` 再来一局 · `P` 换人 | 点按钮 |

### 金币与商人

击杀掉金币：普通怪 2、精英 8、Boss 40。**金币跨图保留**，换图不清零。
每张图的商人密室里摆三件货，走近自动开面板，每件每图限购一次：

| 商品 | 价格 | 说明 |
|---|---|---|
| 治疗药剂 | 160 | 回复 40% 最大生命。这一排里最贵的一件：它买的是「再撑一段」 |
| 破甲弹 ×3 | 60 | Boss 战的入场券，最便宜——不该让玩家因为穷而卡关 |
| 战术手册 | 120 | 立刻一张升级卡 |

### 关底 Boss

每章走完出一个关底，一场 25~45 秒。Boss 身上有壳：**普通武器和技能打不进去**，
只有地上捡的**破甲弹**能打穿，而且**只在它破甲的那几秒里**打得进去。

| 阶段 | 时长 | Boss | 你要做的 |
|---|---|---|---|
| 连招 | 4~6 秒 | 定身 · 无敌 · 连续出招 | 读前摇、躲。新招式「裂地」会在地上连开 5 处，落点跟着你的跑向预判 |
| **破甲** | **3.0 秒** | 定身 · 可被破甲弹打伤，血条与本体转金色，屏幕中央提示音 | 贴上去把弹打空 |
| 追击 | ≤2.4 秒 | 走向你 | 拉开距离，准备下一轮 |

血条右侧常驻一行状态字（`攻击中 · 无敌` / `破甲 2.4s`），不用去找。
三章合计要 **69 发**破甲弹，弹只在这三场里掉（约 1.4~1.6 秒一枚），所以打得动打不动
取决于你在窗口里捡没捡、打没打，和卡片强度无关。

## 本地运行

需要 Godot 4.7.2。

```bash
# 编辑器里跑
godot --path .

# 直接跑
godot --path . MY主场景.tscn
```

没有触摸屏的电脑也想试摇杆，加 `-- --touch` 强制开触屏模式（此时用鼠标拖就是手指）。

## 导出 Web 并发布

```bash
./deploy_pages.sh            # 导出 + 推送到 gh-pages 分支
./deploy_pages.sh --no-export   # 只重推现有 build/web
```

脚本会把 `build/web` 里的产物打进一份**只有单个提交**的临时仓库强制推送，
所以 40MB 的 wasm 不会在分支历史里逐次堆叠。

本地预览（不要用 `file://` 直接打开，必须走 HTTP）：

```bash
python serve.py 8080          # http://127.0.0.1:8080/
python serve.py 8080 --lan    # 同一 Wi-Fi 的手机也能打开
```

## 兼容性

- 渲染后端固定 **GL Compatibility**（Web 唯一可用的后端）
- 用 **nothreads** 模板导出，不依赖 `SharedArrayBuffer`，所以 GitHub Pages 这类无法下发
  `Cross-Origin-Opener-Policy` 的静态托管也能直接跑
- 字体内嵌 `Noto Sans SC` 子集（Web 上 `SystemFont` 会静默退化，必须内嵌）
- 存档存在浏览器 IndexedDB 的 `/userfs` 下，换设备不同步
