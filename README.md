# 暗夜幸存者

一个用 **Godot 4.7.2** 写的 Vampire Survivors 类自动战斗生存游戏。桌面和手机浏览器都能直接玩。

**在线试玩：<https://xumingxian29.github.io/MYGAME/>**

---

## 玩法

存活越久分数越高。角色自动攻击，你只需要走位；升级时三选一加强属性；蓝条满了放一次主动技能。

**地图是一间间迷宫房**：每张图程序化生成 9 个房间 + 走廊，墙是实心的，绕不进去。
其中一间是**商人密室**——走进去就能用金币买药。打完整张图的 Boss 会在原地开**四扇传送门**
（单卡 / 双卡 / 破甲弹 +3 / 金币 +90），**踩上去不会直接走**，面板里点「继续前进」才传。

**四扇门对应四种难度涨幅**，奖励越大代价越大，门前直接写着「+XX%」：

| 门 | 奖励 | 敌人属性涨幅 |
|---|---|---|
| 单卡 | 1 张升级卡 | **+20%** |
| 破甲弹 | +3 发 | **+40%** |
| 金币 | +90 | **+60%** |
| 双卡 | 2 张升级卡 | **+100%** |

涨幅是**加法累加**到难度系数上的（`1 + 累计涨幅`），不是连乘。连乘的话，只要走过一次
+100% 的门，第五张图就是 32 倍，任何流血都救不回来。现在走四扇门各一次是 +220%，
走四扇双卡门是 +400%——「一直贪双卡」会很痛，但痛得可预期。

**墙是真的墙**：玩家、小怪、Boss 都不会生成在墙里，也无法走进墙里；攻击同样不能穿墙——
子弹撞墙即灭，近战和回旋镖在命中前要做视线采样。隔着墙角偷输出不可行。

**每张图的敌人属性按难度系数放大**，没有时间上限——死了才结算。

**升级只给卡，不回血；传送也不回血**。血只有四个来源：脱战自然回复、Boss 战后 15%、
通关补满、商人。所以「这一波要不要绕回商人那儿」是一个真的要权衡的决定。

**视野里同时最多 40 只怪**（Boss 战仍是 10 只）。超出的会被推回屏幕外等着，
而不是原地蒸发——屏外仍然排队，但画面里的压力是恒定的。
上限从 20 提到 40 是为了让后期的「清场感」真的成立：40 只怪铺满屏幕的时候，
清掉一片的反馈是看得见的，而不是屏幕上永远只剩五只。

### 升级与属性上限

每张卡给的数值**不是**直接乘上去的，而是先累加成一个「原始值」，再走一条饱和曲线：

```
最终倍率 = 1 + (3 - 1) × raw / (raw + (3 - 1))
```

于是第一张攻击卡大约 +19.8%（几乎没折扣），第十张只剩几个点，四十张卡合计 **2.63 倍**——
**永远到不了 3 倍，3 倍是天花板而不是目标**。这就是「前面提升多、后面提升少」：
它让前五个升级的每一下都摸得到，又让后期不会因为卡多而变成滚雪球。

曲线只作用于**数值类**（伤害、攻速、移速、血量、拾取范围……）。计数类（额外弹道、
穿透 +1、环绕飞刃 +1）不受曲线约束，因为「多一发子弹」这件事没法打折。

### 三个职业

| 职业 | 定位 | 血量 | 主动技能 |
|---|---|---|---|
| 战士 | 近战 · 高血 | 180 | **旋风斩**：1.2 秒无敌，劈开并击退周围敌人 |
| 法师 | 远程 · 高伤 | 100 | **奥术新星**：大范围爆伤，命中者减速 2.5 秒 |
| 射手 | 远程 · 高射速 | 110 | **箭雨**：向四周射出 14 支穿透箭矢 |

### 操作

| | 桌面 | 手机（横屏） |
|---|---|---|
| 移动 | `WASD` / 方向键 | 左下虚拟摇杆（推一半就是半速） |
| 技能 | `空格` | 右下技能键（蓝条满时变金色） |
| 暂停 / 继续 | `P` / `ESC` | 右上「暂停」键（暂停后变成「继续」） |
| 返回主菜单 | 先按 `P`/`ESC`，再点面板里的「返回主菜单」 | 先点「暂停」，再点面板里的「返回主菜单」 |
| 升级选卡 | 点卡片 或 `1` `2` `3` | 点卡片 |
| 死亡后 | `R` 再来一局 · `P` 换人 | 点按钮 |

### 金币与商人

击杀掉金币：普通怪 6、特殊怪（冲锋 / 吐息 / 自爆）9、精英 24、Boss 120，
并且**每深入一张图 +30%**。**金币跨图保留**，换图不清零。

每张图的商人密室里摆三件货，走近自动开面板，每件每图限购一次：

| 商品 | 基础价 | 说明 |
|---|---|---|
| 治疗药剂 | 1600 | 前三图回复 **5%** 最大生命，第 4 图起固定 **100 点**。这一排里最贵的一件 |
| 破甲弹 ×3 | 600 | 装到武器上：下一次攻击自动变成穿甲弹。最便宜——不该让玩家因为穷而卡关 |
| 战术手册 | 1200 | 立刻一张升级卡 |

**价格每深入一张图 +45%**（`基础价 × (1 + 0.45 × 图数)`）。涨幅比金币的 +30% 快，
所以「越深越贵」是真的有负担，而不是数字变大、购买力不变。
第 6 张图的药剂要 5200，那时候一瓶 100 点血要不要买，是个决定。

### 关底 Boss

每章走完出一个关底，一场 25~45 秒。Boss 身上有壳：**普通武器和技能打不进去**
（打在壳上是一记冷色闪光，血条不动）。

**破甲弹是开火即消耗**：手上有一发，下一次攻击就会变成穿甲弹——子弹、近战挥砍、
回旋镖投掷都行。命中必有效果，不再是「打早了白扔」：

- **打在破甲窗口里** → 40 点满额伤害，并且**把窗口续 0.6 秒**。手上有弹、打得够准，
  就可以把一只 Boss 的窗口无限续住。
- **打在窗口外** → 只有半额 20 点，但会**直接把 Boss 打进破甲**。这是「主动开窗」，
  代价是你多花了半发。

**Boss 血条贴屏幕最顶部整宽一条**（名字 + 血条 + 阶段 + 状态字），左右两栏永远为它让位，
所以开战时 HUD 不会跳一下。

| 阶段 | 时长 | Boss | 你要做的 |
|---|---|---|---|
| 连招 | 4~6 秒 | 定身 · 无敌 · 连续出招 | 读前摇、躲。新招式「裂地」会在地上连开 5 处，落点跟着你的跑向预判 |
| **破甲** | **3.0 秒**（可被续） | 定身 · 可被破甲弹打伤，血条与本体转金色，屏幕中央提示音 | 贴上去把弹打空 |
| 追击 | ≤2.4 秒 | 走向你 | 拉开距离，准备下一轮 |

血条右侧常驻一行状态字（`攻击中 · 无敌` / `破甲 2.4s`），不用去找。
三章合计要 **69 发**破甲弹（每发 40 点满额算），弹只在这三场里掉（约 1.4~1.6 秒一枚），
所以打得动打不动取决于你在窗口里捡没捡、打没打，和卡片强度无关。

## 本地运行

需要 Godot 4.7.2。

```bash
# 编辑器里跑
godot --path .

# 直接跑
godot --path . MY主场景.tscn
```

没有触摸屏的电脑也想试摇杆，加 `-- --touch` 强制开触屏模式（此时用鼠标拖就是手指）。

## 导出 Web 并发布

```bash
./deploy_pages.sh            # 导出 + 推送到 gh-pages 分支
./deploy_pages.sh --no-export   # 只重推现有 build/web
```

脚本会把 `build/web` 里的产物打进一份**只有单个提交**的临时仓库强制推送，
所以 40MB 的 wasm 不会在分支历史里逐次堆叠。

本地预览（不要用 `file://` 直接打开，必须走 HTTP）：

```bash
python serve.py 8080          # http://127.0.0.1:8080/
python serve.py 8080 --lan    # 同一 Wi-Fi 的手机也能打开
```

## 兼容性

- 渲染后端固定 **GL Compatibility**（Web 唯一可用的后端）
- 用 **nothreads** 模板导出，不依赖 `SharedArrayBuffer`，所以 GitHub Pages 这类无法下发
  `Cross-Origin-Opener-Policy` 的静态托管也能直接跑
- 字体内嵌 `Noto Sans SC` 子集（Web 上 `SystemFont` 会静默退化，必须内嵌）
- 存档存在浏览器 IndexedDB 的 `/userfs` 下，换设备不同步
